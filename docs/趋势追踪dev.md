# 板块萌芽期识别系统 · 开发文档

版本：v1.0（与产品需求文档 v1.0 配套）
技术栈建议：Python 3.10+，pandas，numpy。单机即可运行，无需数据库（十年日线数据用列式文件存储足够）。

---

## 一、总体架构

系统分五层，严格单向依赖，上层只消费下层输出：

```
原始数据层  →  清洗层  →  板块聚合层  →  打分层  →  信号与回测层
```

每层落盘一份中间文件（建议 parquet 格式），好处：
1. 每层可单独校验，出错好定位；
2. 重跑打分不必重跑清洗，节省时间；
3. 回测与实盘日常运行共用前四层，只有第五层行为不同。

## 二、第一层：原始数据层

### 2.1 输入文件

**个股日线**（使用者已有），逐行为：日期、代码、开盘、收盘、最高、最低、成交量。

**行业对照表**（需获取），逐行为：代码、行业板块。

### 2.2 复权问题（本项目最大的数据坑）

判断方法：抽几只有过拆股历史的知名股票，检查数据中拆股日前后价格是否出现无成交异动的断崖。若有断崖，说明是未复权价格。

处理方案（按优先级）：
1. 最好：换用前复权价格数据源；
2. 次好：另行获取拆股与分红事件表，自行计算复权因子；
3. 兜底：用"当日收盘 ÷ 前日收盘 − 1"计算涨跌幅时，对单日涨跌幅超过±40%的记录做异常标记并剔除该股当日数据（拆股通常表现为−50%左右的假暴跌）。兜底方案有误伤，仅在前两条都做不到时使用，且要在回测报告中注明。

## 三、第二层：清洗层

按需求文档第四章执行，输出"干净日线表"。伪代码：

```python
def clean(daily, industry_map):
    df = daily.merge(industry_map, on="代码", how="inner")   # 查不到行业的自动剔除
    df = df[df["成交量"] > 0]
    df = df[df["收盘价"] >= 1.0]
    # 上市天数过滤：每只股票保留其第61个交易日之后的记录
    df["序号"] = df.groupby("代码").cumcount()
    df = df[df["序号"] >= 60]
    # 涨跌幅
    df["涨跌幅"] = df.groupby("代码")["收盘价"].pct_change()
    df = df.dropna(subset=["涨跌幅"])
    # 复权兜底：异常跳变剔除（若已用复权价，此行可注释）
    df = df[df["涨跌幅"].abs() <= 0.40]
    return df
```

## 四、第三层：板块聚合层

输出"板块日度表"，每行为：日期、板块、板块涨跌幅、上涨占比、板块成交额、参与个股数。

```python
def aggregate(df):
    df["成交额"] = df["成交量"] * df["收盘价"]
    g = df.groupby(["日期", "行业板块"])
    out = g.agg(
        板块涨跌幅=("涨跌幅", "mean"),          # 等权平均
        上涨占比=("涨跌幅", lambda s: (s > 0).mean()),
        板块成交额=("成交额", "sum"),
        个股数=("涨跌幅", "size"),
    ).reset_index()
    out = out[out["个股数"] >= 20]              # 样本太少的板块当日不产生分数
    # 大盘基准：全市场等权平均
    mkt = df.groupby("日期")["涨跌幅"].mean().rename("大盘涨跌幅")
    out = out.merge(mkt, on="日期")
    out["超额收益"] = out["板块涨跌幅"] - out["大盘涨跌幅"]
    return out
```

## 五、第四层：打分层（核心）

### 5.1 防未来函数的铁律

**任何滚动计算，窗口只许向过去看。** pandas 中一律使用 `rolling(...)` 的默认右对齐，严禁 `center=True`，严禁 `shift(-n)`。暴涨上限的分位数计算也必须用"截至当日的过去二百五十日"滚动分位，不许用全样本分位（全样本分位会把未来的分布信息泄漏给过去）。

**自查方法**：完成开发后，做"截断测试"——取任意历史日期T，只喂给系统T之前的数据，算出T日分数；再喂全量数据，取出T日分数。两者必须完全相等。不等即存在未来函数，必须修复后才能进入回测。这个测试写成自动化用例，每次改代码都跑。

### 5.2 参考实现

```python
import numpy as np
import pandas as pd

def score_sector(sec: pd.DataFrame) -> pd.DataFrame:
    """sec: 单个板块按日期升序排列的日度表。返回含三个子分与萌芽分的表。"""
    s = sec.sort_values("日期").copy()

    # ---- 暴涨上限：过去250日超额收益的98分位（滚动，只看过去）----
    s["暴涨上限"] = (
        s["超额收益"].rolling(250, min_periods=120).quantile(0.98).shift(1)
    )  # shift(1)确保当日不参与自己的上限计算

    # ---- 子分一：稳赢天数分（回看20日）----
    def day_credit(row):
        if pd.isna(row["暴涨上限"]):
            return np.nan
        if row["超额收益"] > row["暴涨上限"]:
            return -0.5
        if row["超额收益"] > 0:
            return 1.0
        return 0.0
    s["单日记分"] = s.apply(day_credit, axis=1)
    s["稳赢计数"] = s["单日记分"].rolling(20, min_periods=20).sum()
    s["稳赢天数分"] = (s["稳赢计数"] / 12).clip(0, 1) * 100

    # ---- 子分二：广度扩散分 ----
    近5 = s["上涨占比"].rolling(5, min_periods=5).mean()
    前5 = s["上涨占比"].rolling(5, min_periods=5).mean().shift(5)
    s["扩散差"] = 近5 - 前5
    s["广度扩散分"] = (s["扩散差"] / 0.10).clip(0, 1) * 100

    # ---- 子分三：量能爬坡分 ----
    量近5 = s["板块成交额"].rolling(5, min_periods=5).mean()
    量前5 = s["板块成交额"].rolling(5, min_periods=5).mean().shift(5)
    s["量能比"] = 量近5 / 量前5

    def vol_score(r):
        if pd.isna(r):
            return np.nan
        if r <= 1:
            return 0.0
        if r <= 1.5:
            return (r - 1) / 0.5 * 100
        if r <= 2:
            return 100.0
        return 20.0          # 脉冲爆量，短炒特征，只给低分
    s["量能爬坡分"] = s["量能比"].map(vol_score)

    # ---- 合成 ----
    s["萌芽分"] = (
        0.4 * s["稳赢天数分"] + 0.4 * s["广度扩散分"] + 0.2 * s["量能爬坡分"]
    )
    return s

def score_all(sector_daily: pd.DataFrame) -> pd.DataFrame:
    scored = (
        sector_daily.groupby("行业板块", group_keys=False).apply(score_sector)
    )
    # 当日全市场排名分位（0=最强）
    scored["当日排名分位"] = scored.groupby("日期")["萌芽分"].rank(
        ascending=False, pct=True
    )
    return scored
```

## 六、第五层：信号与回测

### 6.1 信号生成

```python
def signals(scored: pd.DataFrame, 进场阈值: float, 离场阈值: float) -> pd.DataFrame:
    out = []
    for name, s in scored.groupby("行业板块"):
        s = s.sort_values("日期").copy()
        条件 = (
            (s["萌芽分"] >= 进场阈值)
            & (s["广度扩散分"] > 0)
            & (s["当日排名分位"] <= 0.30)
        )
        s["进场"] = 条件 & 条件.shift(1, fill_value=False) & 条件.shift(2, fill_value=False)

        广度归零 = (s["广度扩散分"] <= 0)
        s["广度连续归零"] = 广度归零.rolling(5).sum() >= 5
        s["离场"] = (s["萌芽分"] < 离场阈值) | s["广度连续归零"]
        out.append(s)
    return pd.concat(out)
```

持仓状态机：未持有时遇"进场"→次日开盘买入；持有中遇"离场"→次日开盘卖出。同一板块持有期间忽略重复进场信号。

### 6.2 回测框架要点

1. **成交价**：信号日的**次日开盘价**。用信号日收盘价成交是隐性未来函数（收盘时你还没算完分数）。
2. **成本**：单边千分之一。
3. **样本切分**：前七年标定、后三年检验，检验段阈值锁死（需求文档 8.1）。
4. **阈值标定**：在标定段对进场阈值（例如 50 到 75，步长 5）× 离场阈值（进场阈值减 5 到减 20）做网格遍历，记录每组的检验指标；**选择的标准不是收益最高的那组，而是"表现良好且相邻阈值组表现相近"的平台区**——孤立的尖峰是过拟合，平台才是真信号。
5. **两个基准**（需求文档 8.2）必须在同一成本假设下计算，否则不可比。

### 6.3 回测输出报告（最低要求）

- 阈值网格表：每组阈值在标定段与检验段的年化收益、最大回撤、信号次数、胜率；
- 选定阈值组在检验段的净值曲线，与两个基准同图；
- 每笔交易清单：板块、进场日、离场日、持有天数、收益；
- 截断测试通过记录（见 5.1）。

## 七、日常运行模式

回测通过、阈值锁定后，日常运行 = 每天增量执行第一到第五层，输出当日表格：

| 板块 | 萌芽分 | 稳赢 | 广度 | 量能 | 排名分位 | 状态 |
|---|---|---|---|---|---|---|
| （示例）软件 | 67 | 75 | 62 | 55 | 前12% | 持有中 |
| （示例）生物医药 | 63 | 58 | 71 | 48 | 前18% | **新触发进场** |
| （示例）能源 | 41 | 50 | 0 | 60 | 前55% | **触发离场** |

状态列只有四种：无、新触发进场、持有中、触发离场。

## 八、开发顺序建议（每步都可单独验收）

1. **第一步**：跑通清洗层+聚合层，人工抽查三个板块、各五个交易日的"上涨占比"是否与原始数据手数一致。
2. **第二步**：实现打分层，先跑最近一年，画出几个板块的萌芽分曲线，肉眼检查是否与行情常识相符（大涨板块启动前分数是否抬升）。
3. **第三步**：写截断测试并通过（防未来函数，最重要的一步）。
4. **第四步**：实现信号与状态机，人工核对五笔进出场信号的触发日期。
5. **第五步**：完整回测+阈值网格+报告。
6. **第六步**：包装成日常运行脚本。

每一步没验收通过，不进入下一步。

## 九、已知风险与提醒

1. **行业对照表是静态快照**：个股行业归属会变、退市股会消失。用"今天的对照表"回测十年，隐含幸存者偏差（已退市的股票不在表里）。缓解：若能获取含退市股的历史成分数据最好；不能的话，在回测报告中注明此偏差，并理解回测结果会因此**偏乐观**。
2. **本策略是趋势跟随类**，在长期无主线、板块快速轮动的市场环境中会反复止损，这是此类策略的固有性格，不是缺陷；回测报告中应单独查看这类时段的回撤。
3. **阈值一经检验段锁定，实盘不许随行情临时改动**。要改，必须重新走一遍标定+检验流程。
4. 一切示例数字（十二天、0.10、1.5倍等）属于算法结构的一部分，已尽量用相对值定义；若开发中发现某个写死数字导致信号极端稀少或极端频繁，回到标定段用网格法处理，不要凭感觉改。
