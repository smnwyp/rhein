## 2. 架构分层

这是**研究管线**的分层，不是交易管线。数据从上往下单向流动。

```
L1 原始数据层     load 日线 + 板块映射；复权校验
L2 清洗层         对齐交易日历；缺失/停牌处理；极端值处理
L3 板块聚合层     stock → sector：等权板块收益 / 上涨家数占比(广度) / 板块成交额
L4 特征层         萌芽分三分量 + 合成分；前向超额收益 F_N
L5 统计检验层     IC / 分位 / HAC / 逐年 / 稳健性 / 分量归因
────────────────────────────────────────────
L6 合成对照自检层  正对照 / 负对照 / 置换检验 / 手算单测（L5 的守门人）
L7 可视化层       7 张图 + 一页研究报告
```

> **INV-1 落地**：L5 的所有数据结构（IC 序列、分位表、检验结果对象）在定义时就**不包含**净值 / 年化 / 收益率累计 / 回撤字段。用 dataclass / pydantic 显式定义这些结构，让"年化"这类字段在 L5 根本无处安放。评审时只要看到 L5 出现 P&L 字段，即为架构违规。

> **INV-5 落地**：L6 是 L5 触真实数据的**前置闸门**。主流程入口先跑 L6 四关，全 pass 才允许把真实数据喂给 L5；任一关 fail，主流程抛异常终止，打印失败的关卡。见 §7 开发顺序与 §5。

## 3. 关键计算定义（防未来函数是重点）

用**宽表**（wide format）作为 L3–L5 的主数据结构：行 = 交易日 `date`，列 = 板块 `sector`。宽表让"同一天、跨板块"的横截面操作变成一次按行运算，既快又不容易写出未来函数。

主要宽表：
- `R`：板块日收益（L3）
- `U`：板块日上涨家数占比 / 广度（L3）
- `V`：板块日成交额（L3）
- `mkt`：市场基准日收益 = `R.mean(axis=1)`（全板块等权，Series）
- `RE`：板块日超额收益 = `R.sub(mkt, axis=0)`
- `S`：萌芽分（L4）
- `F_N`：前向 N 日超额收益（L4），每个 horizon 一张

### 3.1 时间对齐约定（未来函数的生死线）

**决策点 t：** 第 t 日收盘时，`S(t, ·)` 只允许使用 **≤ t** 的数据。

**前向超额收益：**
```
板块前向收益   sec_fwd(sector, t) = close(sector, t+N) / close(sector, t) − 1
市场前向收益   mkt_fwd(t)         = 全板块等权的同窗前向收益
F_N(sector, t) = sec_fwd(sector, t) − mkt_fwd(t)
```
`F_N(t)` 用的是 **> t** 的未来收盘价，但它是"结果"，不是"决策依据"；决策点 t 的 `S(t)` 不含任何未来信息。**这条界线在实现里必须显式注释：哪些量用 ≤t、哪些量用 >t。** 样本末尾最后 N 天无法形成完整前向窗口，须丢弃并记录丢弃数量。

> 任何用到 `.rolling()` / `.shift()` 的地方，shift 方向和窗口对齐要单独写单测（见 §5 手算单测），这是最容易出 off-by-one 未来函数的地方。

### 3.2 市场基准
`mkt(t) = R(t, ·).mean()`（当日全板块等权平均收益）。这是 beta baseline；所有"超额"都相对它算，横截面上大盘涨跌被天然扣掉（INV-2）。

### 3.3 萌芽分三分量（精确公式）

设当前日为 t，`RE` 为超额收益宽表，`U` 为广度宽表，`V` 为成交额宽表。

**稳赢天数分** `steady(t)`
```
窗口 W1 = 过去 20 个交易日 (t-19 … t)
暴涨上限 cap(t) = RE 在过去 250 个交易日的 98 分位（滚动、逐板块各自算）
逐日计分 d ∈ W1:
    if RE(d) > cap(t):  contribution = −0.5      # 惩罚暴力冲高
    elif RE(d) > 0:     contribution = +1
    else:               contribution = 0
count = Σ contribution
steady = min(max(count, 0) / 12, 1) × 100
```

**广度扩散分** `breadth(t)`
```
recent = U 在 (t-4 … t) 的均值
prior  = U 在 (t-9 … t-5) 的均值
diff = recent − prior
breadth = min(max(diff, 0) / 0.10, 1) × 100        # 负则 0，0.10 封顶
```

**量能爬坡分** `volramp(t)`
```
recent = V 在 (t-4 … t) 的均值
prior  = V 在 (t-9 … t-5) 的均值
ratio = recent / prior
if ratio <= 1:            volramp = 0
elif ratio <= 1.5:        volramp = (ratio − 1) / 0.5 × 100      # 线性
elif ratio <= 2.0:        volramp = 100
else:                     volramp = 20                           # 惩罚脉冲爆量
```

**合成** `S(t) = 0.4 × steady + 0.4 × breadth + 0.2 × volramp`

> 权重与所有窗口常数（20, 250, 0.98, 12, 5, 0.10, 1.5, 2.0）全部从 config 读入，但**本阶段禁止对它们做网格搜索或择优**（INV-3）。config 存在只是为了集中管理与可复现，不是为了调参。

### 3.4 IC 计算
```
对每个 horizon N:
  对每个交易日 t（从有效起点到末尾-N）:
     取当日同时有有效 S(t,·) 和 F_N(t,·) 的板块子集
     若有效板块数 < k_min（默认 5，见 §3.5）: 跳过该日，记入 skipped_days
     IC_N(t) = spearman_rank_corr( S(t, valid), F_N(t, valid) )
  得到 IC 序列 {IC_N(t)}
```
每日同时报告"有效板块数"，供事后判断横截面是否够厚。

### 3.5 分位数分析
```
每日按 S(t,·) 把板块分成 Q 档（默认 Q=5）
  guard: 若当日有效板块数 < 2*Q，降级档数（5→3→top/bottom），并记录降级日
每档 = 该档内板块当日 F_N 的均值 → 得到"当日 × 各档"的收益矩阵
跨日平均 → 每档平均随后超额收益
Top−Bottom 价差序列（每日 Q_top − Q_bottom）→ 其均值 + HAC t（§4.3）
单调性 = 检查 Q1<Q2<…<Q5 是否成立（报告，不做硬 assert）
```
`k_min` 与 `Q` 的最终取值取决于 PRD §3.2 板块粒度定板——**板块定义确定前，这两个常数先留占位，别写死。**

### 3.6 逐年分解
把 `IC_N(t)` 和 Top−Bottom 价差序列按自然年 groupby，逐年报告均值与符号。

### 3.7 分量归因
用 §3.3 的三个分量各自当作"分数"，各跑一遍 §3.4 的 IC，与合成分 IC 并列输出。定位预测力住在哪个分量。

## 4. 统计细节

### 4.1 Spearman 秩相关
每日在板块横截面上算。可用 `scipy.stats.spearmanr`，或自己 `rankdata` 后求 Pearson——两种都行，但要写单测对齐（§5 手算单测里含一个 IC 手算值）。当日有效板块 < k_min 跳过。

### 4.2 为什么必须做重叠窗口修正
horizon = N 时，相邻两天的前向收益窗口重叠 N−1 天，于是相邻的 `IC_N(t)` **强自相关**。朴素标准误 `std(IC)/sqrt(T)` 把这 T 个观测当独立，会**严重高估有效样本量**——看起来上万个观测，有效独立样本可能只有一两百个。后果：t 统计量虚高，"显著"是假的。这正是上一版最容易骗人的地方。

### 4.3 Newey-West / HAC 标准误（手写，可审计）

对一条序列 `x`（比如 `IC_N` 或 Top−Bottom 价差），估计其均值的 HAC 标准误，滞后阶 `L = N`：

```
T = len(x)
xbar = mean(x)
e = x − xbar
γ_0 = (1/T) Σ_t e_t²
γ_j = (1/T) Σ_{t=j+1..T} e_t · e_{t−j}       for j = 1..L
S_hac = γ_0 + 2 · Σ_{j=1..L} (1 − j/(L+1)) · γ_j      # Bartlett 核加权
se_hac = sqrt( S_hac / T )
t_hac  = xbar / se_hac
```

`(1 − j/(L+1))` 是 Bartlett 核，随滞后线性衰减、保证方差估计非负。**直觉：这个修正把相邻 IC 的自相关吃进方差里，让标准误变大、t 变小，还原真实的有效样本量。** 这十几行是整套显著性判断的关键，务必配一个已知答案的单测（构造一段已知自相关的序列，核对 t_hac 与手算/参考实现一致）。

### 4.4 非重叠稳健性核对
另做一条：每 N 个交易日抽一个样本点（互不重叠），在这批独立样本上重算 IC 均值与朴素 t。它与 §4.3 的 HAC 结论应当一致；不一致说明自相关结构没处理干净，需排查。两法互为交叉验证。

## 5. 合成对照自检层（L6）—— "验证算得对"的核心

这是 INV-5 的落点，也是你明确要的"验证计算正确"的机制。**四关全部写成 `assert`，作为主流程的前置闸门，也进 CI。** 每关的原理是构造一个**已知真相**的数据集，看管线能不能还原它。

### 关 1 · 正对照（有信号必须测得出）
```
直接构造 (score, fwd_excess)，不经过价格：
    score ~ 标准正态（N_days × N_sectors）
    fwd_excess = β · standardize(score) + ε,  ε ~ 噪声
    β 调到目标 IC ≈ 0.10
断言：
    管线测出的 IC 均值 ≈ 0.10（容差如 ±0.02）
    分位数单调递增，Top−Bottom > 0 且 HAC t 显著
含义：管线在"确实有信号"时能把信号还原出来，且量级正确。
```

### 关 2 · 负对照（没信号绝不能乱报）
```
score 与 fwd_excess 相互独立随机
断言：
    IC 均值 ≈ 0（落在 0 附近的容差带内）
    在 α=0.05 下不显著
    重复 M 次（如 M=200），假阳性率 ≈ α（不显著高于 5%）
含义：管线在"纯噪音"上不会凭空造出显著性。假阳性率超标 → HAC 或 IC 有 bug。
```

### 关 3 · 置换 / shuffle 检验（证明无前视泄漏）
```
在真实（或合成价格）管线里，把每一天 S(t, ·) 的板块标签随机打乱，
其余不动，重算 IC。
断言：打乱后 IC ≈ 0。
含义：真实结论若来自信号而非泄漏，打乱标签就该抹掉它。
      若打乱后仍显著 → 管线存在 lookahead / 对齐错误，真实结论作废。
```

### 关 4 · 手算单测（抓 off-by-one / 未来函数）
```
构造微型数据：3 个板块 × ~30 天，数值人为设定。
手算：steady / breadth / volramp / S / F_N / 某一日 IC 的精确值。
断言：函数输出与手算值逐值相等（数值容差极小）。
重点覆盖：rolling/shift 的窗口对齐、cap 的 98 分位、量能分段函数的边界（ratio=1, 1.5, 2.0）。
含义：抓窗口对齐里的未来函数与边界错误——这是最隐蔽的一类 bug。
```

**闸门逻辑**：主流程 `run_real_study()` 第一步调用 `run_synthetic_gate()`；四关任一 fail 即 raise，禁止继续。让"没过自检就碰真实数据"在代码层不可能发生，而不是写在注释里提醒。

## 6. 可视化层（L7）规格

逐图给定：输入、坐标轴、期望形态、验证目标。标签英文，报告中文。

1. **IC time series** — x=date, y=daily IC；叠加 rolling mean 与 y=0。验证预测力持续性。
2. **Cumulative IC** — x=date, y=Σ daily IC。稳步上行=持续信号；随机游走=噪音。
3. **IC histogram** — daily IC 分布，标 mean 与 0。验证正负质量、偏态。
4. **Quintile bar** — x=Q1..Q5, y=平均随后超额收益。单调递增=信号成立。**核心裁决图。**
5. **Quintile cumulative** — Q1..Q5 各一条累计随后超额曲线。扇形张开、Q5 顶 Q1 底=区分度持续。
6. **Yearly IC bar** — x=年, y=当年 IC 均值。各年同号=稳定；单年独撑=侥幸。
7. **Synthetic control panel** — 正对照 vs 负对照并排，各含图 4/6。**验证管线本身不自欺**：正对照必须显单调、负对照必须全平。

> 每张图存 PNG，并汇入一页 Markdown / HTML 研究报告，报告顶部先打印 §7 预注册判据的四条逐条 pass/fail，再放图。让"结论"先于"图"，避免看图凑结论。

## 7. 开发顺序（thin-slice，先窄后宽）

沿用你主项目的 autonomous progression 精神：每步交付一个**可自检的增量**，开发者可自验自提交，不必每步等你。

**IT-1 · 纯统计引擎 + 合成对照**（不碰真实数据、不碰价格聚合）
只做 L5 的 IC / 分位 / HAC + L6 四关。输入是合成数组。
**交付闸门**：合成对照四关全过。这是最小可验证切片——统计核对了，后面才有意义。

**IT-2 · 板块聚合 + 萌芽分**（L3 + L4 的 score 部分）
stock → sector → 三分量 → 合成分。
**交付闸门**：置换检验（关 3）在真实数据结构上跑通且 IC≈0，证明无泄漏。

**IT-3 · 前向超额 + 全统计量 + 逐年 + 分量归因**（L4 的 F_N + L5 全量）
接上 IT-1 的引擎，跑出完整统计量。
**交付闸门**：非重叠稳健性核对与 HAC 一致。

**IT-4 · 可视化 + 研究报告**（L7）
7 张图 + 一页报告，顶部逐条打印预注册判据 pass/fail。

**IT-5 · 真实数据首跑 + 三分支裁决**
过前置闸门 → 喂真实数据 → 按 PRD §7 出裁决。

> IT-1 必须最先做且独立可跑：如果连"已知信号能不能被测出、纯噪音会不会误报"都过不了，真实数据的一切结论都无从谈起。

## 8. 已知坑 / 开发者须知

- **复权校验（L1）**：三级方案——① 优先用复权价；② 有复权因子则用因子还原；③ 检测到未复权（如单日 −50% 又非真实暴跌的 split 特征）则拒绝并报错，不静默带病运行。
- **幸存者偏差**：结论页显式标注"基于当前股票池回填，偏乐观，真实只会更差"。
- **板块数**：每日报告有效板块数；数太少时 IC 与分位都会噪声大，别掩盖。
- **禁网格（INV-3）**：config 里参数一次定死，代码里不留"遍历参数选最优"的路径。
- **禁 P&L 字段（INV-1）**：L5 数据结构里不得出现净值 / 年化 / 收益率累计 / 回撤 / 夏普。评审看到即打回。
- **前置闸门（INV-5）**：`run_real_study()` 不得绕过 `run_synthetic_gate()`。
- **时间对齐**：所有 rolling/shift 处显式注释 ≤t / >t，并被手算单测覆盖。
