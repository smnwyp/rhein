# 回测 UI 使用说明

启动本地界面：

```bash
.venv/bin/streamlit run app.py
```

## 自然语言策略解释器

从 Streamlit 侧边栏打开“自然语言策略解释器”。该页面与主回测页面共享
“标的分组”选择；策略保存到跨组策略库，而不是某一个分组目录。

左侧“策略”区域有两条明确路径：

- **新建策略**：输入自然语言后点击“解释策略”。
- **已保存策略**：载入已验证策略或仅有原文的草稿；已验证策略可直接使用，
  草稿可载入后继续解释。保存策略可保留原文，即使 DSL 尚未生成。

解释器遇到会改变交易含义而原文没有说明的内容，会展示精确的选择题或输入框。
例如“低点”使用 Low 还是 Close、“不低于 t0”中的参考价格，以及“较 t0-2
高 0.01%”是相对变化还是绝对差。回答后仍由同一个解释器继续处理，不会切换到
另一个 Agent。

### 解释审阅

解释成功后，“解释审阅”展示的不是 JSON，而是以下可核对信息：

1. 原始策略全文；
2. 原文被拆分后的 `C01…Cn` 条件；
3. 每条条件的处理状态、实际 DSL 路径和中文解释；
4. DSL 的中文规则展开；
5. 带同名 C 标签的合成 t0 相对日 K 线时间轴。

合成 K 线仅用于理解条件的时序关系，不是任何标的的真实行情，也不参与回测。
若一段原文不能映射、只能在假设下映射、或当前不支持，审阅表会明确显示；系统
不会在解析成功时悄悄遗漏它。

v0.3 已支持窗口内“先高点 A、后低点 B”的有序回撤、C 点以来的扩张窗口最大
成交量，以及十字星或大阴线的显式形态公式。并列极值固定取**最早**出现的日期。
这类策略还必须明确“样本结束时未平仓如何处理”及“卖出后是否可再次寻找 C 点”；
没有答案时，页面先在本地展示澄清题，不会调用模型或默默采用默认值。

### 解释器回测

解释器页面的“回测结果”默认页可针对当前选择的分组运行已支持的 v0.2/v0.3 时序
策略。该路径调用确定性 Python 回测，而非 LLM；结果包含 KPI、Top 100 和选中
交易的 K 线。v0.3 只按日线收盘价成交，不会伪造盘中路径；旧 v0.2 日线实现对于
明确启用的盘中止损采用当日 Low 的保守近似。无法保持语义的 DSL 会被拒绝，而不
会被静默简化。

左侧“数据范围”可直接选择示例数据、全部 Nasdaq 当前股票池，或任一“流动性－波动”特征组；选择后单组回测和参数扫描都会自动使用该目录。选择“自定义路径”时，才需要手动输入数据目录或单个 CSV 路径。

已完成两阶段搜索的特征组会额外显示“参数预设”。选择“使用本组盈利因子最高组合”会从该目录的 `search_metadata.json` 读取参数和成本假设。该预设仅是盈利因子最高的历史候选；页面会同时显示其回撤代理，不能替代 15% 组合最大回撤验收。

## 单组回测

- `t0 单日涨幅区间` 对应动量信号带，例如 `2.0–2.5`。
- 默认使用固定仓位：每笔均以初始资金计算。需要复利时，在左侧显式打开“使用复利”。
- `入场确认日` 的 `t2` 表示在信号日后第 2 个交易日，且当日收盘价不低于 t0 收盘价时入场。
- 每条策略条件都有独立开关，默认均开启；关闭即不参与筛选或出场。t0 区间、低点不在 t0、相对低点最大涨幅、RSI 上限均可分别启停。
- 入场仅考察 tN-1、tN，不使用 tN+1。`tN≥t0`、`收盘价>快线MA`、`快线MA>慢线MA`、`短期均量>长期均量` 是四条独立条件；启用的条件须在确认窗口的同一天同时成立。
- `早期止损观察日` 使用相对 t0 的编号。例如 t2 入场时填 `3,4`；t3 入场时可填 `4,5`。
- “早期止损使用收盘价触发”紧邻止损幅度；未勾选时使用盘中最低价触发，默认未勾选。勾选时以收盘价触发并按收盘价出场。
- 早期止损、后期“跌破入场价”与“跌破 MA”均可分别启停。早期观察窗口结束后的下一交易日起，任一启用的后期条件触发即按收盘价出场；两个后期条件均关闭时仅会在数据结束平仓。
- `EX-04 强制平仓` 是固定持有期基准，默认关闭。平仓日以 t0 表示，默认 t5；因此 t2 入场时会在 t5 收盘强制平仓。选择日必须晚于入场确认日；若同日早期止损先触发，则早期止损优先。
- `EX-05 强制平仓日日内保护` 仅在 EX-04 当天生效。默认幅度为入场价下 1%；若盘中任意即时价格触及该位，立即按保护价（跳空则按开盘价）出场，否则仍在 EX-04 当天收盘强制平仓。日线回测以 `Low ≤ 保护价` 判断当天是否曾触及该即时价格。该规则可独立关闭。
- 仅在选定特征组时可使用“本组已保存组合”：填写名称并保存当前参数后，组合会写入该组专属的 `saved_combos.json`。之后从同一处选择并加载即可回填所有开关与数值；不同组之间不会互相显示或覆盖。
- 在“单组回测与 Top 100”中点击任一标的行，可选择该标的的一笔交易并查看日 K 线。图上会标出 t0 基准点、入场点与出场点，窗口为 t0 前 10 个交易日至出场后 10 个交易日。
- 运行后可按盈利因子、总盈亏、胜率、盈亏比、平均收益或最大回撤查看 Top 100，并下载 KPI 与逐笔交易 CSV。表头使用中文；悬停表头或在“指标定义”中选择指标名称，可查看公式与统计口径。

## 参数组合扫描

以逗号输入候选范围，例如 `2-2.5, 2-3`；界面会与候选确认日、止损幅度和 MA 做笛卡尔组合。扫描为每个组合生成跨标的汇总指标和可下载 CSV。

全 Nasdaq 数据池的多组合扫描会比较耗时。建议先把“最多读取多少个标的”设为 100–300 验证参数范围，再对全量数据运行最终候选组合。
