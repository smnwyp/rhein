# 板块萌芽期识别系统 · 产品需求文档（PRD）

版本：v1.0
适用市场：纳斯达克（个股日线数据），后续可迁移至A股
文档性质：给开发者的需求说明。所有算法定义以本文为准，开发文档负责讲"怎么实现"。

---

## 一、系统要解决的问题

散户投资者没有精力追逐每天变换的短线热点，也承受不起"两天暴拉、随后拍死"的假热点风险。本系统的目标是：

**在一个板块从"冷"变"微温"的最早阶段（萌芽期）就把它识别出来，给使用者留出数周的时间去调研个股、分批建仓、安心持有。**

系统必须同时做到两件事：

1. **识别萌芽**：找出正在被资金持续、温和、系统性买入的板块。
2. **过滤短炒**：主动排除依靠单日暴力资金冲高、缺乏内在扩散逻辑的假热点。

系统输出的是**每日更新的量化分数和明确的进出场信号**，使用者看到数值即可决策，不需要盯盘。

## 二、设计原则（不可违背）

1. **严禁未来函数**。任何一天的分数，只能使用该日（含）之前的数据计算。回测中若发现任何指标引用了未来数据，属于最高级别缺陷。
2. **相对值优先于绝对值**。所有阈值尽量用"全市场分位数"表达，而不是写死的绝对数字，以适应牛熊不同环境。
3. **慢信号优先**。宁可晚进、少赚，不可被单日脉冲骗进。所有进场条件都要求"连续多日成立"。
4. **离场看机制，不看盈亏**。离场信号由"萌芽逻辑被破坏"触发（广度收缩、持续性中断），而不是由账面亏损触发。
5. **回测的目的是杀死策略，不是美化策略**。回测必须与朴素基准对比，跑不赢基准则整套否决。

## 三、输入数据

### 3.1 个股日线表（使用者已有）

| 字段 | 说明 |
|---|---|
| 日期 | 交易日 |
| 代码 | 个股代码 |
| 开盘价 / 收盘价 / 最高价 / 最低价 | 当日价格 |
| 成交量 | 当日成交量 |

覆盖范围：纳斯达克几乎全部个股，约十年历史。

### 3.2 行业对照表（需另行获取）

| 字段 | 说明 |
|---|---|
| 代码 | 个股代码 |
| 行业板块 | 该股所属行业分类 |

- 建议使用标准行业分类（十一个一级行业），公开渠道可获取。
- 没有这张表，系统无法运行。这是唯一的外部前置依赖。
- 对照表中查不到行业的个股，剔除，不参与任何计算。

### 3.3 大盘基准

用"全市场所有入选个股的等权平均日涨跌幅"作为大盘基准，不依赖外部指数数据。（也可替换为纳斯达克综合指数日线，二选一，全程保持一致。）

## 四、数据清洗规则

1. 剔除上市不满六十个交易日的新股（数据不足以计算指标）。
2. 剔除当日成交量为零或停牌的记录。
3. 剔除价格低于一美元的个股（仙股噪音大，易扭曲板块广度）。
4. 个股涨跌幅按收盘价环比计算；若数据中含拆股、分红导致的价格跳变，必须使用复权价格，否则涨跌幅失真。**若原始数据未复权，开发时必须先解决复权问题，这是数据层面最大的坑。**
5. 每个板块每日参与计算的个股数不足二十只时，该板块当日不产生分数（样本太少，广度指标无意义）。

## 五、板块日度指标（中间层）

对每个板块、每个交易日，计算三个基础量：

1. **板块日涨跌幅**：板块内全部个股当日涨跌幅的等权平均。
2. **上涨家数占比（广度）**：板块内当日上涨的个股数 ÷ 板块内当日参与计算的个股总数。
3. **板块总成交额**：板块内全部个股的（成交量 × 收盘价）之和。用成交额而不是成交量，避免低价股虚增量能。

同时计算大盘基准日涨跌幅（见 3.3）。

## 六、核心算法：萌芽分（零到一百）

萌芽分由三个子分数加权合成：

**萌芽分 = 稳赢天数分 × 0.4 + 广度扩散分 × 0.4 + 量能爬坡分 × 0.2**

### 6.1 稳赢天数分（权重四成）

衡量"持续温和跑赢"，惩罚"暴力冲高"。

- 回看窗口：过去二十个交易日。
- 逐日计算板块超额收益 = 板块日涨跌幅 − 大盘日涨跌幅。
- 计数规则：
  - 超额收益 > 0 且 ≤ 暴涨上限：记 +1 天；
  - 超额收益 > 暴涨上限：记 −0.5 天（暴力冲高是短炒特征，倒扣）；
  - 其余：记 0。
- **暴涨上限不写死**，定义为：该板块过去二百五十个交易日超额收益分布的第九十八百分位。（美股波动温和，经验上大约落在一点五到两个百分点附近；用分位数定义可自适应不同市场。）
- 稳赢天数分 = min(计数 ÷ 12, 1) × 100。即二十天里稳赢十二天即满分。

### 6.2 广度扩散分（权重四成）

衡量"参与上涨的个股是否越来越多"，这是区分真萌芽与一两只妖股撑场面的核心。

- 近五日平均上涨家数占比 − 前五日（第六到第十日）平均上涨家数占比 = 扩散差。
- 广度扩散分 = clip(扩散差 ÷ 0.10, 0, 1) × 100。即占比十个百分点的扩散即满分；扩散差为负记零分。

### 6.3 量能爬坡分（权重两成）

衡量"成交是否温和放大"，惩罚脉冲爆量。

- 量能比 = 近五日平均成交额 ÷ 前五日平均成交额。
- 计分规则：
  - 量能比 ≤ 1：零分；
  - 1 < 量能比 ≤ 1.5：线性给分，即 (量能比 − 1) ÷ 0.5 × 100；
  - 1.5 < 量能比 ≤ 2：满分一百；
  - 量能比 > 2：只给二十分（脉冲爆量，短炒特征）。

### 6.4 输出

每个交易日，对每个板块输出：萌芽分、三个子分数、以及萌芽分在当日全部板块中的排名。

## 七、进出场信号规则

### 7.1 进场信号

同时满足以下全部条件时，标记该板块为"进入萌芽期"：

1. 萌芽分**连续三个交易日** ≥ 进场阈值；
2. 三天中每一天，广度扩散分 > 0（扩散必须真实存在）；
3. 该板块萌芽分位于当日全市场板块的**前百分之三十**以内。

### 7.2 离场信号

满足以下任一条件时，标记"萌芽逻辑破坏，离场"：

1. 萌芽分跌破离场阈值（离场阈值 < 进场阈值，形成缓冲带，避免在阈值附近反复进出）；
2. 广度扩散分**连续五个交易日**为零（上涨家数占比持续收缩，内在扩散逻辑已死）；
3. 单日出现"暴涨上限"以上的超额收益且次日广度占比下降（脉冲出货形态）。

### 7.3 阈值的确定方式（重要）

进场阈值与离场阈值**不在本文档中写死**。它们必须通过回测（见第八章）在历史数据上标定。文档中出现的一切示例数字（如六十、五十）仅为演示，严禁直接用于实盘。

## 八、回测与验收标准

### 8.1 回测规则

- 用十年数据，前七年作为标定段（尝试不同阈值组合），后三年作为检验段（阈值锁死不许再动）。
- 交易假设：信号出现次日以开盘价成交；计入单边千分之一的摩擦成本。
- 仓位规则（简化版）：每个触发进场的板块等权买入该板块等权组合，离场信号出现即全部卖出。

### 8.2 必须输出的回测指标

1. 每次进场信号后的胜率与平均持有期收益；
2. 策略净值曲线 vs 两个基准：(a) 简单持有大盘；(b) 朴素动量基准——"每月初买入过去二十日相对强弱排前百分之二十的板块，持有一个月"；
3. 最大回撤；
4. 信号次数（十年信号少于二十次则样本不足，结论不可信）。

### 8.3 验收标准（不达标即否决整套策略）

1. 检验段（后三年，阈值锁死）中，策略必须同时跑赢两个基准；
2. 检验段最大回撤不得大于简单持有大盘的最大回撤;
3. 标定段表现极好、检验段大幅衰减（收益腰斩以上）则判定为过拟合，回到第六章重新简化算法，而不是继续调阈值。

**特别强调**：如果这套复杂算法跑不赢那个朴素动量基准，正确结论是"放弃这套复杂算法、用朴素动量"，而不是继续加参数。

## 九、日常使用形态（最终交付物）

开发完成后，使用者每天的操作流程：

1. 更新当日个股日线数据；
2. 运行程序；
3. 程序输出一张表：全部板块按萌芽分排序，标出"新触发进场""持有中""触发离场"三种状态；
4. 使用者据此决策，无需盯盘。

## 十、明确不做的事（边界）

1. 不做个股选择——系统只到板块层面，板块内选股由使用者自行调研；
2. 不做日内交易——全部基于日线，信号最快次日执行；
3. 不预测涨幅——只判断"萌芽逻辑是否成立"；
4. 不保证收益——系统的价值上限由回测决定，回测不过关则整套否决。
